## 为什么要写博客

记录学习过程、沉淀技术笔记，是工程师成长的有效方式。借助 GitHub Pages + Hexo，我们可以：

- 零成本托管静态站点
- 用 Markdown 专注写作
- 一键部署到公网

## 一段代码示例

```bash
# 本地预览
hexo clean && hexo server

# 生成并部署
hexo generate --deploy
```
